Detailed Description

The top-level Bounding Volume Hierarchy tree manager.

  • The BVH tree organizes AABBs spatially to reduce O(N^2) collision checks down to O(log N). It uses a contiguous array of nodes to avoid cache misses caused by fragmented heap pointers.
