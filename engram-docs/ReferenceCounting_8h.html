Detailed Description

Thread-safe (if implemented with atomics) manual memory management.

This system implements the "Retain/Release" pattern. It is used for shared resources like Textures, Shaders, and Mesh data to ensure they are only freed when no systems (Renderer, Asset Registry, or GameObjects) are currently using them.
