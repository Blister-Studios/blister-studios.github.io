Detailed Description

A single node within the Bounding Volume Hierarchy tree.

  • This structure uses a Data-Oriented Design (DOD) optimization trick to keep its memory footprint small. If count is 0, the node is an internal branch. If count is greater than 0, the node is a leaf containing physical geometry.
