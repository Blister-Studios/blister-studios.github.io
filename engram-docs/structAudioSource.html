Detailed Description

Component managing the playback of audio assets within the game world.

  • The AudioSource is responsible for controlling volume, pitch, and looping behavior. It supports a hybrid backend approach: it uses FMOD for professional-grade spatial audio or falls back to a simple frame-based software mixer if FMOD is disabled.
