#define HAS_ATOMICS   0

Preprocessor flag indicating atomic hardware support.

  • 1 if the current build supports thread-safe atomic operations, 0 otherwise.
  • Use this flag in your implementation to toggle between atomic increments
  • and standard non-thread-safe increment operations.

Typedef Documentation

◆ rc_count_t

rc_count_t

Thread-safe counter type used for reference counting.

Thread-safe counter type used for reference counting.

  • This type abstracts the underlying atomic implementation. If the compiler
  • and architecture support C11 atomics, this resolves to atomic_ptrdiff_t.
  • Otherwise, it falls back to a standard ptrdiff_t.
