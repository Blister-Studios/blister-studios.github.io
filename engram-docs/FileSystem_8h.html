Detailed Description

Virtual File System (VFS) for platform-independent asset addressing.

The VFS allows the engine to map virtual paths (e.g., "res://textures/hero.png") to actual physical locations on the disk. This abstraction layer enables easier asset management, modding support, and cross-platform path handling.
