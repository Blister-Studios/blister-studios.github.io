Detailed Description

A mathematical ray used for line-of-sight and intersection queries.

  • Includes precalculated inverse direction values. This optimizes the "Slab Method" algorithm used for fast Ray-to-AABB intersection tests, replacing expensive division operations with faster multiplications inside the loop.
