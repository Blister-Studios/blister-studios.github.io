Detailed Description

A unified, high-level draw command sent to the rendering backend.

  • Engine systems (like SpriteRenderer or MeshRenderer components) build a
  • list of these packets every frame. They are type-erased to allow the
  • backend to sort and batch them efficiently before hitting the GPU.
