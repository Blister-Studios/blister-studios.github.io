Detailed Description

Maps a virtual URL prefix to a physical directory on the disk.

  • The VFS uses this to redirect requests. For example, if virtual_prefix is "res" and physical_base is "C:/Game/Assets/", a request to "res://ships/player.png" is resolved to "C:/Game/Assets/ships/player.png".
