void * resource_load ( EngramContext *  ctx,
const char *  v_path 
)

Loads a resource from a virtual path.

This function resolves the path via the VFS, checks if the resource is already in the cache, and if not, uses the appropriate loader.

Parameters
ctxThe engine context.
v_pathThe virtual path to the asset (e.g., "res://hero.png").
Returns
A reference-counted pointer to the asset, or NULL on failure.
