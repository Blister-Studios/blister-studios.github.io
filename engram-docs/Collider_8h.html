Detailed Description

Component for physical intersection testing and spatial registration.

  • The Collider component acts as the interface between a GameObject's Transform and the engine's Bounding Volume Hierarchy (BVH) system. Colliders are automatically registered into the BVH tree during the collider_awake cycle.
