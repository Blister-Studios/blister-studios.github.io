Detailed Description

Per-instance data for hardware instanced rendering.

  • When rendering multiple copies of the same mesh (e.g., thousands of bullets or trees), this data is submitted in a separate vertex buffer with a step-rate of SG_VERTEXSTEP_PER_INSTANCE. It defines the unique state of each copy.
