Engram Engine

A lightweight, highly-extensible C framework built for raw performance and rapid iteration.

Integrated Editor

Real-time scene manipulation, entity inspection, and direct feedback through the custom viewport.

Lua Virtual Machine

Hot-reloadable Lua scripting bindings injected directly into the C core for fast gameplay logic iteration.

Component Architecture

Strict data-driven GameObject and Component hierarchy (Transform, Sprite, Script, Camera).

Custom VFS

A robust Virtual File System handling path resolution, physical mapping, and secure asset loading.

Data Serialization

Full JSON serialization for Scenes and Prefabs, allowing the engine state to be saved and loaded instantly.

No_Std Philosophy

Engineered to minimize dependencies, passing contexts explicitly to maintain clean architecture and memory safety.
